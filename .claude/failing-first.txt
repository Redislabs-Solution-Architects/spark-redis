# Tests committed failing ahead of their fix (CLAUDE.md rule 5).
#
# A bug's test lands first, failing, in its own commit. Its fix comes after, and must make the test pass without
# changing it. .claude/hooks/protect-paths.sh blocks agent edits to every test listed here, so the agent that fixes
# a bug can't weaken the test that proves it.
#
# One repo-relative test file per line, then "#" and the issue or findings entry, for example:
#   src/test/scala/com/redislabs/provider/redis/rdd/cluster/MovedWriteClusterSuite.scala  # #347
#
# The PR that fixes the bug removes the test's line and leaves the test as it is: scripts/check-failing-first.sh
# fails a PR that removes a line and also changes or deletes its test, and the test jobs show that it passes. A
# line removed in the working tree keeps protecting its test until the removal is committed.
